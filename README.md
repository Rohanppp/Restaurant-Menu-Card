# The Hungry Hub - Indian Cuisine Menu

![The Hungry Hub Cover](./images/The%20hungry%20hub.png)

A beautiful and responsive Indian restaurant menu page built with HTML and CSS, featuring authentic Indian cuisine, vibrant colors, and comprehensive menu sections.

## 🍽️ Project Overview

This project is a complete restaurant menu website for "TheHungry Hub" - an authentic Indian restaurant. The website showcases a professional menu with traditional Indian dishes, beautiful styling with Indian-inspired colors, and responsive design that works perfectly on all devices.

### HTML Structure
- **Semantic HTML5** elements for better accessibility and SEO
- **Structured sections** for different menu categories
- **Tables** for organized menu item display
- **Navigation menu** with smooth scrolling
- **Image integration** for visual appeal
- **Footer** with restaurant information

### CSS Styling
- **Modern design** with gradient backgrounds and shadows
- **Responsive layout** that adapts to all screen sizes
- **Beautiful table styling** with hover effects
- **Typography** using Google Fonts (Playfair Display & Open Sans)
- **Smooth animations** and transitions
- **Print-friendly** styles for physical menus

### Menu Sections
1. **Appetizers & Starters** - Traditional Indian snacks and starters
2. **Main Courses** - Signature Indian curries and dishes
3. **Desserts & Sweets** - Traditional Indian sweets and desserts
4. **Beverages & Drinks** - Indian drinks and beverages
5. **Chef's Specials** - Featured daily creations

## 🛠️ Technologies Used

- **HTML5** - Semantic markup and structure
- **CSS3** - Modern styling with Flexbox and Grid
- **Google Fonts** - Typography enhancement
- **Responsive Design** - Mobile-first approach

## 🚀 Getting Started

### Prerequisites
- A modern web browser (Chrome, Firefox, Safari, Edge)
- A text editor (VS Code, Sublime Text, etc.)

### Installation
1. Clone or download this repository
2. Open `index.html` in your web browser
3. For development, use a local server (optional)

### Running the Project
```bash
# Simply open index.html in your browser
# Or use a local server:
python -m http.server 8000
# Then visit http://localhost:8000
```

## 🔧 Customization

### Adding Images
1. Replace placeholder images in the `images/` folders with authentic Indian food photos
2. Ensure images are optimized for web (recommended: 300x300px)
3. Use descriptive filenames matching the HTML references
4. Consider using images of traditional Indian dishes like samosas, biryani, butter chicken, etc.

### Modifying Menu Items
1. Edit the table content in `index.html`
2. Update prices and descriptions as needed
3. Add or remove menu items by copying table row structure

### Styling Changes
1. Modify colors in `styles.css` to match your preferred Indian color scheme
2. Adjust fonts by changing Google Fonts imports
3. Customize layout using CSS Grid and Flexbox
4. Add more Indian-inspired patterns or textures if desired
